# 스마트공장기능사 필기

스마트공장기능사 필기 문제은행 1,207문항으로 연습·종합시험을 푸는 도구입니다.

- 주소 : https://hongyul67-cpu.github.io/smart-factory-cbt/ (암호 잠금)
- 대상 : 스마트공장기능사 필기 준비 (스마트팩토리·메카트로닉스)
- 만든 날 : 2026-09-21

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 범위 고르기 → 연습 8문항 → 종합시험 20문항 → CBT 실전 60문항 → 오답노트 → 제출 |
| `data/bank.js` | 문제은행 (자동 생성 · **커밋하지 않음**) |
| `build_bank.py` | 전사본 JSON 16개 → `data/bank.js` 굽기 |
| `bank.enc` | 배포되는 문제은행 — AES-GCM 암호화 |
| `build_lock.py` | `data/bank.js` → `bank.enc` 굽기 |
| `rubric.json` | 결과수집이 세특 문장·성취수준을 만들 때 쓰는 평가 루브릭 |

## 문제은행 굽기

문항은 `index.html` 에 없습니다. 전사 작업방에서 가져와 굽습니다.

```
python build_bank.py
```

읽는 곳 : `../_작업/스마트공장 전사/_src/문항/*.json` (예상문제 13챕터 + CBT 3회)

| 칸 | 뜻 |
|---|---|
| `i` `c` `s` `p` | 아이디 · 챕터 · 절 · 책 쪽 |
| `q` `o` `a` `e` | 발문 · 보기 4개 · 정답(0부터) · 해설 |
| `d` | 중복 문항이면 먼저 나온 아이디 — **무작위 출제에서 뺀다** |
| `x` | 1이면 보기를 섞지 않는다 (해설이 "①, ③, ④는…" 처럼 보기 번호를 가리키는 문항) |

| 묶음 | 문항 |
|---|---|
| 예상문제 `SF_BANK` | 1,027 (중복 32 빼면 출제 대상 995) |
| CBT 모의고사 `SF_EXAMS` | 3회 × 60 = 180 (🖥️ CBT 실전 탭에서 씁니다) |

## CBT 실전 — 60문항 · 60분

교재 462쪽에 실린 실제 시험 화면을 본떴습니다.

- **글자 크기**(기본/확대) · **화면 배치**(1단/2단/3단) · **계산기** · **제한 시간 60분과 남은 시간**
- 오른쪽 **답안 표기란** — 번호를 누르면 그 문제로 건너뛰고, 동그라미를 눌러도 답이 표기됩니다.
  🔖 는 다시 볼 문제 표시
- 시험 중에는 점수·정답·해설을 **전부** 감춥니다. `fx.js` 연출과 `rank.js` 계급도 붙이지 않습니다(연습 모드에만)
- 시간이 다 되면 그때까지 표기한 답으로 자동 채점합니다. 남은 시간은 **실제로 흐른 시간** 기준이라
  창을 닫아 두어도 시계는 갑니다(이어서 보기)
- 끝나면 채점 → 합격선 60점(36문항) 표시 → 오답노트(표기 안 한 문제 포함) → 결과 제출
- 회차는 책 순서 그대로 60문항을 냅니다. **보기는 섞습니다** — 책 정답이 ②에 몰려 있어
  안 섞으면 '모르면 ②'가 통합니다(검수보고 2항)
- 시험 중에는 브라우저 `confirm`·`alert` 창을 쓰지 않습니다(화면 안 알림창)

## 왜 암호가 걸려 있나

문항은 「2026 스마트공장기능사 필기」(건기원) 512쪽을 옮긴 것입니다.
저작권법 제25조는 수업 목적 이용을 허용하되 **접근 제한 조치**를 요구하므로,
화면만 가리는 방식이 아니라 **파일 자체를 실제로 암호화**했습니다.

- `bank.enc` 주소를 직접 열어도 알아볼 수 없는 문자열만 나옵니다
- 브라우저에서 암호로 키를 만들어(PBKDF2-SHA256 200,000회) AES-GCM 으로 풉니다
- 검색엔진 차단(`robots.txt`)
- 암호는 두 가지 — 교사용(만료 없음)과 그 주만 쓰는 학생용 8자리 코드.
  교사용으로 열면 **그 주 학생 코드가 화면에 나옵니다.** 기간은 암호문 안에 들어 있어
  화면이나 `index.html` 을 고쳐도 넘길 수 없습니다
- **한 번 연 기기는 다음부터 그냥 열리고**, 같은 주소의 다른 도구도 함께 풀립니다

> 이 저장소에 평문 문항은 없습니다(`data/bank.js` 는 `.gitignore`).
> 암호와 주간 코드 시크릿은 저장소 밖 `_weekly/secret.json` 에 있습니다.

```
python build_bank.py    # 전사본 JSON -> data/bank.js (평문, 이 PC 전용)
python build_lock.py    # data/bank.js -> bank.enc (배포본)
```
